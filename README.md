# Featured Projects

## OutcomeLink

**Outcomes Management & Accreditation Reporting Platform**

A full-stack outcomes management system for career and technical colleges built with **TypeScript, React, Express, Prisma, and MySQL**.

OutcomeLink tracks student completion, employment, licensure, and continuing-education outcomes while calculating **Completion, Placement, and Licensure (CPL)** rates used for accreditation reporting. The system is designed around complex real-world business rules, with every calculated rate providing student-level drill-downs explaining why individual students are counted or excluded.

The project demonstrates full-stack application architecture, complex business-rule implementation, multi-tenant data management, authentication and authorization, automated testing, CI/CD, containerized deployment, and production-oriented software design.

### Key Features

- Student enrollment and outcomes management
- Employment, licensure, and continuing-education tracking
- Completion, Placement, and Licensure rate calculations
- Configurable accreditation rule sets and program benchmarks
- Student-level drill-down for calculated metrics
- Reporting-period management and closeout workflows
- Risk indicators for programs trending below established targets
- Cohort and demographic outcome analysis
- Privacy suppression for small demographic groups
- Multi-institution architecture with institution-scoped data
- Role-based access control with program-level authorization
- User and program assignment management
- Bulk SIS / Excel data import with validation and preview
- Scheduled report delivery
- Evidence-document collection and linking
- Structured application logging
- Background processing and scheduled jobs
